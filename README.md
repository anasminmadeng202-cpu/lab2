# README.md
# โครงงานระบบคำนวณราคาสินค้า (Order Calculator)

## 1. ความเป็นมาของโปรแกรม
โปรแกรม Order Calculator เป็นโปรแกรมที่พัฒนาด้วยภาษา JavaScript ใช้สำหรับคำนวณราคาสินค้า ส่วนลด ภาษีมูลค่าเพิ่ม (VAT 7%) และยอดเงินสุทธิที่ลูกค้าต้องชำระ

การทำงานของโปรแกรมช่วยให้การคำนวณราคาสินค้ามีความถูกต้องและลดข้อผิดพลาดจากการคำนวณด้วยตนเอง

## 2. สิ่งที่ได้เรียนรู้

จากการทำงานนี้ ได้เรียนรู้เรื่องต่าง ๆ ดังนี้

1. การสร้างไฟล์ JavaScript นามสกุล `.js`
2. การประกาศตัวแปรด้วย `const`
3. การสร้างฟังก์ชันด้วย `function`
4. การรับค่าพารามิเตอร์ เช่น ราคา จำนวนสินค้า และส่วนลด
5. การใช้เงื่อนไข `if` เพื่อตรวจสอบข้อมูล
6. การใช้ `throw new Error()` เพื่อแจ้งข้อผิดพลาด
7. การคำนวณยอดรวมสินค้าและส่วนลด
8. การคำนวณภาษีมูลค่าเพิ่ม VAT 7%
9. การใช้ `toFixed(2)` เพื่อกำหนดทศนิยม 2 ตำแหน่ง
10. การใช้ `console.log()` เพื่อแสดงผลลัพธ์

## 3. ความสามารถของโปรแกรม

- รับราคาสินค้า
- รับจำนวนสินค้า
- รับเปอร์เซ็นต์ส่วนลด
- ตรวจสอบราคาสินค้าต้องมากกว่า 0
- ตรวจสอบจำนวนสินค้าต้องมากกว่า 0
- ตรวจสอบส่วนลดให้อยู่ระหว่าง 0-100%
- คำนวณยอดรวมสินค้า
- คำนวณส่วนลด
- คำนวณภาษี VAT 7%
- แสดงยอดเงินสุทธิที่ต้องชำระ

## 4. สูตรการคำนวณ

**1. ยอดรวมสินค้า**

subtotal = price × quantity

**2. จำนวนเงินส่วนลด**

discount = subtotal × (discountPercent ÷ 100)

**3. ภาษีมูลค่าเพิ่ม**

VAT = (subtotal - discount) × 0.07

**4. ยอดชำระสุทธิ**

grandTotal = subtotal - discount + VAT

## 7. วิธีการรันโปรแกรม

1. เปิดโปรแกรม Visual Studio Code
2. สร้างไฟล์ชื่อ `orderCalculator.js`
3. เขียนโค้ด JavaScript ลงในไฟล์
4. บันทึกไฟล์
5. เปิด Terminal
6. พิมพ์คำสั่ง

```bash
node orderCalculator.js
```

7. กด Enter เพื่อรันโปรแกรมและดูผลลัพธ์

## 8. สิ่งที่ได้รับจากการเรียนรู้

จากการทำโปรแกรมนี้ทำให้ได้เรียนรู้พื้นฐานภาษา JavaScript เข้าใจการสร้างฟังก์ชัน การกำหนดตัวแปร การใช้เงื่อนไข การตรวจสอบข้อมูล และการคำนวณทางคณิตศาสตร์

นอกจากนี้ยังได้ฝึกแก้ไขข้อผิดพลาดในการเขียนโปรแกรม และเรียนรู้การใช้ AI เป็นเครื่องมือช่วยตรวจสอบโค้ดและเสนอแนวทางการทดสอบโปรแกรม

## 9. สรุป

โปรแกรม Order Calculator เป็นตัวอย่างการนำภาษา JavaScript มาใช้แก้ปัญหาในชีวิตประจำวัน โดยสามารถคำนวณราคาสินค้า ส่วนลด และภาษีมูลค่าเพิ่มได้อย่างเป็นระบบ

การทำงานครั้งนี้ช่วยให้เข้าใจพื้นฐานการเขียนโปรแกรม JavaScript มากขึ้น และสามารถนำความรู้ไปต่อยอดในการพัฒนาเว็บไซต์และระบบขายสินค้า (POS) ในอนาคตได้
